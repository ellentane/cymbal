# AGENTS.md

Baseline rules for all work in this repository. They take precedence over any
tool's default behavior, including automatic commits.

## Never commit

- AI-generated artifacts: specs, design docs, implementation plans,
  brainstorming output, session summaries, scratch notes.
- Anything under `docs/superpowers/` or other AI-work directories.
- Files carrying AI attribution: "generated by", "written with <tool>",
  "AI-assisted" markers — in content or commit messages.
- Secrets, keys, credentials, env dumps, logs.

## Always

- Review `git status` and `git diff` before committing; commit only the
  intended source files.
- Keep source code free of boilerplate comments and AI-style doc comments
  unless explicitly asked.
- Ask the user before committing anything ambiguous: generated files,
  lockfiles, config, docs.

## Git hygiene

- One logical change per commit; complete, intentional changes only.
- Human-authored, meaningful commit messages. No "AI generated" framing.
- Never amend, force-push, or rewrite shared history unless asked.
